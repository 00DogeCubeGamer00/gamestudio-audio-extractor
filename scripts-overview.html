Audio & Chiptune Script Breakdown

Comparison of the 11 Python scripts based on their naming conventions and audio-processing roles.

1. General Audio Ripping & Splitting

Script Name Primary Role Key Difference
audio_ripper.py Base Audio Extractor Standard script for ripping or extracting raw audio tracks from a source.
audio_rippxc.py Extended / Custom Ripper Variant of the base ripper (likely handles custom formats, extra channels, or an extended codec).
audio_splitter.py Track / Stem Divider Splits an existing audio file into smaller segments, timestamps, or individual channels rather than ripping.

2. Bass-Focused Tools

Script Name Primary Role Key Difference
bassyripper.py Bass-Boosted / Low-End Ripper Extracts audio while isolating or emphasizing low-end bass frequencies.
bassymusicconverter.py Full-Track Bass Converter Converts complete music files while applying bass enhancement or low-frequency tuning.
bassyloopconverter.py Seamless Loop Bass Converter Specifically tailored for short audio loops, preserving loop points while converting bass properties.

3. Chiptune & Retro Synth Converters

Script Name Primary Role Key Difference
chipcrunchconverter.py Bitcrusher / Lo-Fi Chiptune Applies heavy bit-depth reduction or sample-rate crunch for a gritty retro sound.
unaliaserchiptuneconverter.py Anti-Aliased Chiptune Converts audio to chiptune style while smoothing out harsh aliasing artifacts and high-frequency distortion.

4. "Specia" FX Series (Progressive Versions)

Script Name Primary Role Key Difference
speciaconverter.py Base Special Converter The original or baseline version of the custom conversion algorithm.
speciaFXconverter.py Special Effects Variant Adds custom audio effects (FX) processing on top of the base converter.
speciaFXXconverter.py Heavy / Extended FX Variant An intensified or second-generation revision of the FX converter with stronger or extra effect chains.
